# Milestone Implementation Plans

Implementation plans are bounded handoffs tied to a repository baseline.

Naming:

```text
implementation/<subsystem>/NNN-short-title.md
```

Each plan contains:

1. objective;
2. why ready;
3. current evidence;
4. invariants;
5. in/out scope;
6. required production changes;
7. ordered work packages;
8. failure/cancellation/restart/contention semantics;
9. compatibility/migration;
10. required tests;
11. verification commands;
12. documentation updates;
13. acceptance criteria;
14. stop conditions;
15. closure evidence;
16. handoff notes.

Correctives receive new milestone numbers and reference the prior plan/closure.
