# Subsystem Roadmaps

Roadmaps are stable, dependency-aware workstream descriptions rather than coding
checklists.

Each roadmap contains:

1. purpose/ownership boundary;
2. work classification;
3. non-goals;
4. current state;
5. target architecture;
6. dependency graph;
7. milestones;
8. cross-cutting requirements;
9. verification strategy;
10. risks/decision points;
11. completion definition;
12. milestone status.

Commit-specific mechanics belong in `plans/implementation/`.
